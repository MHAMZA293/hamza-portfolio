Hamza Portfolio

A modern, responsive 3D portfolio website built with React, Vite, TypeScript, and Framer Motion.
Designed to showcase projects, skills, and creativity with smooth animations and an interactive UI.

Features
Fast and optimized with Vite
Modern responsive UI design
Built with React + TypeScript
Smooth animations using Framer Motion
3D interactive elements
Fully responsive (mobile + desktop)
Ready for deployment on GitHub Pages
Tech Stack
React.js
Vite
TypeScript
Framer Motion
Tailwind CSS
Three.js (if used for 3D elements)
