## Run Locally

Clone the repository:

```bash
git clone https://github.com/MHAMZA293/hamza-portfolio.git
cd hamza-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in your terminal.

---

## Build for Production

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

The production files are generated inside:

```text
dist/
```

## Customization

### Projects

Project information is maintained in:

```text
src/data/projects.ts
```

You can update:

* Project name
* Description
* Technology stack
* GitHub URL
* Live demo URL
* Project image

### Skills

Skills are maintained in:

```text
src/data/skills.ts
```

### Contact

Contact information and footer links can be updated in:

```text
src/sections/Footer.tsx
src/components/ContactButton.tsx
```

### Styling

Global styling and visual tokens are primarily maintained in:

```text
src/index.css
tailwind.config.js
```
